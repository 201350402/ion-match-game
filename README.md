# Ion Match – Starter Game

A drag-and-drop (or tap-to-match) starter activity for Grade 9–10 chemistry.
Students sort formulas into three groups:

- **A** – One atom with a charge (monatomic ion)
- **B** – Several bonded atoms with an overall charge (polyatomic ion)
- **C** – A molecule with no overall charge

Two rounds: the **Starter** (NO₃⁻, H₂O, Na⁺) and the **Al Ain label challenge**
(Ca²⁺, Cl⁻, SO₄²⁻, HCO₃⁻, CO₂, O₂). Wrong answers get a hint; a full match reveals the group names.

Standard: NGSS HS-PS1-1.
